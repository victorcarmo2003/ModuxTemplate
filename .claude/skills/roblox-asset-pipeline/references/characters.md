# Custom R6 characters (e.g. animal crew)

## Base body (shared by every species)

- Separate meshes with exact R6 names: `Head`, `Torso`, `Left Arm`, `Right Arm`, `Left Leg`, `Right Leg`
  (+ `HumanoidRootPart` 2×2×1 invisible). Keep **Torso 2×2×1, limbs 1×2×1** so default R6 animations work.
  Only the head may be bigger (chibi ~2.3×1.75×1.9); then `Neck.C1` changes (e.g. y -0.825; per-animal z offset
  when a snout moves the bbox).
- Standard R6 Motor6D C0 (Part0 side): RootJoint/Neck `(0,0|1,0, -1,0,0, 0,0,1, 0,1,0)`,
  Shoulders `(±1,0.5,0, 0,0,±1, 0,1,0, ∓1,0,0)`, Hips `(±1,-1,0, ...)`. Solve C1 from the imported rest pose:
  `C1 = part1.CFrame:ToObjectSpace(part0.CFrame * C0)` (scripts/studio/build_crew.luau).
- Attachments on the head for swaps: `HatAttachment`, `FaceFrontAttachment`, `EarLeft/EarRightAttachment`,
  `SnoutAttachment`; torso `TailAttachment`, `BodyBack/Front`; hands `Left/RightGripAttachment`.
- Accessories (cap, apron, ears, tail, shell, beak) as separate meshes, welded to Head/Torso where modelled.
- Wave pose: R6 shoulder pivot is at the inner edge of the arm - a big head gets hit by a sideways wave; wave
  forward-and-out. Run a test pose render (wave, holding a Tool, running 45-60°) for gaps/penetration.

## Per species

`Head_<Animal>` (snout, cheeks, eyes), `Ears_<Animal>`, `Tail_<Animal>`, extras (`Shell_Turtle`, `Beak_Owl`).
Ears-up animals need a **cap with ear holes** (one `Cap_EarsUp` for all, holes at the fixed ear attachments);
floppy ears / no ears use the plain cap. Two fur colours (main + secondary) for panda/fox/dog.

## Heads and expressions (textured, cartoon)

- Head = ONE rounded/oval low-poly mesh per species (snout/beak as volume), smooth shaded, no modelled eyes/
  nose/mouth (the user rejected boxy heads with modelled features: "mais texturizado, mais cartonizado").
- Head texture per species = markings only (light muzzle, panda patches, fox mask); alpha 0 = main fur colour.
- **Face shell** `Face_<Animal>`: thin copy of the head's front, pushed ~0.01 out along the normals, with a
  **standardised UV across all species** (eyes, nose, mouth always on the same texels). One expression sheet then
  fits every animal; expression swap = `Face.TextureID` (`Crew.setExpression(model, "Fainted", tex)`).
- Expression set: Normal, Happy, Smile, Sad, Fainted (X eyes), + Night variants (small glowing pupils).
  Use for gameplay states (faint, hit, serve happy/sad customers) and UI portraits.

## Textures (characters are the exception to "no painted textures")

- Clean UV unwrap in a per-character 512² sheet: outfit sheet (torso, limbs, cap, apron; apron front denser for
  the logo) + face sheet (head). Roblox reads **only the first UV channel** - put the paint UV first.
- **Fur by alpha**: transparent texels = fur; the part's `Color` shows through (`MeshPart.Color = fur`), so one
  outfit sheet serves every species. Semi-transparent dark pixels = shading/grime over fur.
- Outfits: crew uniform (cap, apron with an original logo, shirt, pants, shoes) and civilian sets for NPCs.
- **Day / night variants by texture only** (same mesh): day cute/clean/big shiny eyes; night darker, desaturated,
  grime, stains (brown, not blood), small glowing pupils, droopy brows - keep it within the audience rating.
- Night must cover **every** piece: atlas-coloured accessories (ears, tail, shell, beak, cap with ear holes) keep
  day colours unless swapped - make a night copy of the atlas (fur tones toward the night fur, reds like the night
  uniform) and set it as `TextureID` on Night builds (`T_Atlas_Kitchen_Night`, build_crew keeps `DayTextureID`).
- Roblox shows a partial-alpha overlay almost opaque: a 30% navy "worn fur" layer rendered as solid navy (Blender
  previews blend it). Judge night colours in Studio, not in Blender.
- Generated by script (numpy/PIL) worked well for a first pass; upload PNGs with `upload_image` and set
  `TextureID` (they did not embed in the FBX because of the alpha-mix material).
- Budget: 512² RGBA ≈ 1.3 MiB uncompressed with mips, ~340 KB on GPU (BC3); count ×2 for night variants.

## Assembly in Studio

`Crew.build{ ids, tex, animal = "Dog", outfit = "Crew"|"A"|"B", time = "Day"|"Night", fur = Color3,
earsUp = bool, cap = bool, at = CFrame(HRP, ground + 3) }` → Model with Humanoid (R6), Motor6Ds, welds.
Demo row on the map's queue marks is the fastest way for the user to judge them.
